# Prismium

**Vanilla+ performance optimization for Minecraft.**

Prismium is a performance optimization mod focused on improving rendering performance while keeping the vanilla Minecraft experience intact.

## Features

- **Entity Culling** — prevents entities outside the camera view from being rendered.
- **Distant Culling** — controls how far away entities are rendered.
- **Configurable settings** — press **L** by default to open Prismium Settings.
- **Custom keybind** — the Prismium Settings key can be changed in Minecraft's Controls menu.
- **Mod Menu support** — access Prismium Settings directly from Mod Menu.

## Development

Prismium is currently in **Alpha** and is actively being developed.

More performance optimizations, culling options and configuration features are planned for future releases.
